# Люми

Уютная игра с маленькими питомцами для Windows 10/11 x64.

## Скачать

[Открыть последнюю версию](https://github.com/Yadzaba/lumi-releases/releases/latest) — скачайте файл `Lumi-Setup-…exe` и запустите установщик. Вход в GitHub не нужен.

## Первый дом

При первом запуске укажите своё имя. Получите случайное яйцо или нажмите **«Открыть подарок»**, если вам передали файл `.lumi-gift`. Согрейте яйцо несколькими прикосновениями и дайте малышу имя.

Можно кормить питомца, играть, отдыхать, гулять и обустраивать комнату. Аппаратик Core2 для знакомства не нужен. Сейчас доступны моль и лисёнок.

## Обновления и сохранения

В приложении откройте **«Мой дом» → «Сохранение и обновления»**. Проверка новой версии происходит и при запуске; загрузку и перезапуск выбираете вы. Обновления сохраняют питомца и комнату. Для новой версии не нужно снова заводить яйцо.

Профиль хранится локально на компьютере. Это ещё не облачный аккаунт. В том же меню можно сохранить защищённую паролем резервную копию для переноса своего дома.

## Текущий этап

Это ранняя версия игры. Установщик пока без цифровой подписи издателя, поэтому Windows может показать предупреждение о неизвестном издателе.

Перенос новых питомцев в Core2, гости между компьютерами и отношения питомцев ещё разрабатываются. Прежняя Люми продолжает работать с существующим аппаратиком.

Здесь публикуются готовые установщики и файлы обновлений. Личные сохранения сюда не загружаются.
